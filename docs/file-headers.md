# File headers

Every source file opens with a header: the licence and copyright as SPDX tags, then the file's metadata. Copy the template for the file type and fill it in.

## Fields

| Field | Content |
|---|---|
| `SPDX-License-Identifier` | `Apache-2.0`, the licence of the repository ([`../LICENSE`](../LICENSE)) |
| `SPDX-FileCopyrightText` | year of creation and holder: `2026 Hedi Basly`, as in [`../NOTICE`](../NOTICE) |
| File | the path from the repository root, so that each `CMakeLists.txt` is told apart |
| Brief | one sentence: what the file is |
| Element | the software element it belongs to: `Nexus-Physical-01-04 (bootloader)` or `Nexus-Physical-01-05 (FBL-Updater)` ([`requirements.md`](requirements.md)) |
| Decisions | the decision IDs the file implements, cited, never restated; `none` when there are none |
| Details | optional: what a reader needs before the code, wrapped at 100 columns |

Not in the header: author, dates, revision history. Git records them, and a copy kept by hand drifts.

The SPDX tags are machine-readable (the [REUSE](https://reuse.software) tool and licence scanners read them), and they are the copyright notices in the files that `NOTICE` asks a reuser to keep.

## Comment style

C++ comments are `/* */` only, never `//`: the header, the comments in the code and a comment at the end of a line. A comment of several lines is one block with a ` * ` on each line. `#` in CMake files.

## C++ source, `.cpp`

```cpp
/*
 * SPDX-License-Identifier: Apache-2.0
 * SPDX-FileCopyrightText: 2026 Hedi Basly
 */

/**
 * @file      src/boot/main.cpp
 * @brief     One sentence: what the file is.
 *
 * Element:   Nexus-Physical-01-04 (bootloader)
 * Decisions: SW-03, SW-07
 *
 * Optional details.
 */

#include <cstdint>
```

## C++ header, `.hpp`

The same header, then the include guard: `NEXUS_` and the path from the repository root, in capitals, with `/` and `.` as `_`.

```cpp
/*
 * SPDX-License-Identifier: Apache-2.0
 * SPDX-FileCopyrightText: 2026 Hedi Basly
 */

/**
 * @file      src/<module>/<name>.hpp
 * @brief     One sentence: what the file is.
 *
 * Element:   Nexus-Physical-01-04 (bootloader)
 * Decisions: none
 *
 * Optional details.
 */

#ifndef NEXUS_SRC_<MODULE>_<NAME>_HPP
#define NEXUS_SRC_<MODULE>_<NAME>_HPP

#endif
```

A header generated by CMake from a `.hpp.in` names the generated file in `@file` and says in the details that it is generated (`version/version.hpp.in`).

## CMake, `CMakeLists.txt` and `.cmake`

The same fields, as `#` comments.

```cmake
# SPDX-License-Identifier: Apache-2.0
# SPDX-FileCopyrightText: 2026 Hedi Basly
#
# File:      src/CMakeLists.txt
# Brief:     One sentence: what the file is.
# Element:   Nexus-Physical-01-04 (bootloader)
# Decisions: none
#
# Optional details.

foreach(_variant IN LISTS NEXUS_VARIANTS)
```
